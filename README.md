# khooyj.github.io

Personal site, built with Jekyll on GitHub Pages. Live at https://khooyj.github.io

- `index.md` – homepage content
- `_layouts/default.html` – page layout
- `assets/css/style.css` – styles (light/dark, responsive)
- `_posts/` – articles (`YYYY-MM-DD-slug.md`, `layout: post`, set `permalink`, `description`, `tags`; add `mermaid: true` for diagrams)
- `articles.md` – article index at `/articles/`; RSS at `/feed.xml`
